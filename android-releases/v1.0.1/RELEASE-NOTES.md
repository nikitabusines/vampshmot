# 1.0.1

Подключён сервер фоновых RuStore Push для приложения, установленного с GitHub. Исправлено сохранение привязки заказных уведомлений при холодном фоновом запуске без хранения JWT в нативных настройках. Выход из аккаунта явно снимает привязку.

Нативный интерфейс магазина и оформление заказов сохранены. Сервер сайта и Telegram-бот не перезапускались, их код не менялся. Отправитель — отдельный сервис с доступом к бизнес-базе только для чтения. Старая история не рассылается.

Физическая доставка на телефон пока ожидает подтверждения.
