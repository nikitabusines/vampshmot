# Vamp Shmot для Android

[Скачать Vamp Shmot 1.0.0 (APK, 4.54 MiB)](https://github.com/nikitabusines/vampshmot/raw/refs/heads/android-downloads/android-releases/v1.0.0/Vamp-Shmot-1.0.0-release.apk)

Android 8.0 и новее. Package: `ru.vampshmot.app`. Версия: `1.0.0` (код `1`).

## Установка

1. Откройте ссылку на Android-телефоне и скачайте APK.
2. Откройте загруженный файл. Если Android запросит, разрешите установку из вашего браузера или файлового менеджера.
3. Установите Vamp Shmot. Разрешение на уведомления можно включить по желанию.

Обновления нужно устанавливать поверх старой версии, сохраняя приложение и его данные. Все обновления будут подписываться тем же ключом. Не удаляйте приложение перед обновлением, если хотите сохранить корзину и вход.

## Возможности

Каталог магазина, поиск и фильтры, карточки товаров, избранное, корзина, оформление в приложении после входа в аккаунт, история заказов. Сохранённые списки корзины и избранного доступны без сети; актуальные цены и наличие проверяются онлайн.

Локальные уведомления о результате оформления реализованы. Фоновые уведомления RuStore о новых поступлениях и изменении статуса пока требуют активации push-проекта и отдельного отправителя. До подключения они не работают при закрытом приложении.

Приложение использует существующие API магазина. Установка APK не изменяет код сайта или Telegram-бота.
