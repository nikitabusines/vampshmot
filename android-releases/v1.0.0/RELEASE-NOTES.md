# 1.0.0 — первая Android-версия

- Каталог, фотографии товаров, поиск, фильтры, корзина и избранное.
- Оформление заказа через приложение и существующий аккаунт магазина.
- Сохранённые списки без интернета.
- Уведомления о результате оформления с разрешения пользователя.

Проверки: 5 JVM-тестов, 4 Android-теста оформления с имитацией сервера, проверка подписанного release с публичным каталогом, карточкой товара и корзиной. Реальные заказы при проверке не создавались.

Фоновые RuStore Push ещё не активированы. Публикация в RuStore ожидает восстановления консоли и завершения настройки.
