# Vamp Shmot 1.0.1 для Android

[Скачать приложение (APK)](https://github.com/nikitabusines/vampshmot/raw/refs/heads/android-downloads/android-releases/v1.0.1/Vamp-Shmot-1.0.1-release.apk)

Android 8.0+. Package `ru.vampshmot.app`, версия `1.0.1`, код версии `2`. Устанавливается поверх 1.0.0 с сохранением данных; ключ подписи тот же.

## Уведомления

Сервер фоновых push подключён. В приложении откройте **⋮ → Уведомления**, включите **«Уведомлять о новых поступлениях»** и разрешите уведомления Android. Для надёжной доставки установите RuStore на тот же телефон и разрешите ему фоновую работу. Установка самого Vamp Shmot из GitHub поддерживается; публикация приложения в RuStore для push не требуется.

Новые товары проверяются каждые 30 секунд, старая история при подключении не рассылается. Изменения собственных заказов доступны после входа в аккаунт магазина. Исправлено сохранение привязки к аккаунту при фоновом запуске приложения; явный выход снимает привязку. Тест доставки в шторку на физическом телефоне ещё ожидает подтверждения.

## Магазин

Каталог, поиск, фильтры, фотографии и размеры товаров, корзина, избранное и оформление заказа после входа. Сохранённые списки доступны без сети; актуальные цены и остатки проверяются онлайн.
